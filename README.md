# CarCam 行车记录仪 - 通用版
> 适配安卓9（API 28）车机的第三方行车记录仪APP，**通用版不包含厂商私有车控协议**，无品牌绑定，可用于绝大多数安卓9车机。

## 📌 版本说明
- 版本：通用版
- 适配系统：Android 9 (API 28)
- 开发目标：给安卓车机提供独立录像、拍照、局域网回看、外接存储备份能力
- 通用版**不加载私有车控探测、不读取原厂CAN信号，只使用安卓标准能力，兼容性更广

## ✨ 核心功能清单
### 1. 摄像头录像 & 拍照
- 基于Camera2 API实现摄像头预览，GL渲染叠加水印，预览画面不卡顿
- 分段循环录像，自定义存储上限，超出上限自动删除最早视频
- 支持拍照，照片同步叠加水印
- 录像码率可配置，默认1500kbps，适配车机存储
- 录像文件格式：MP4，方便播放器直接打开

### 2. 视频水印（画面叠加信息）
> 水印直接烧录进视频画面，不是预览层悬浮窗，录像文件自带水印
- 顶部单行水印：日期时间、GPS车速、经纬度、VIN码（读到才显示，读不到自动隐藏）
- 水印开关独立控制，可在设置里开启/关闭水印显示
- 水印布局自动适配画面，不会超出屏幕边界

### 3. 局域网网页后台（重点）
- APP内置本地网页服务，同一局域网下其他设备（手机/电脑）可以访问网页
- 自动生成访问二维码，扫码直接打开网页
- 网页功能：实时预览、查看录像列表、查看照片、在线播放、下载文件
- 内置反馈表单二维码、软件更新下载二维码，网页端和APP内均可查看

### 4. 外接存储备份（U盘 / SD卡）
- 自动识别USB存储、SD卡设备
- 支持SAF目录授权（文件管理器式授权），授权后可直接在U盘根目录生成 `CarCam/clips`（录像）、`CarCam/photos`（照片）
- 备份规则：**只备份已经录制完成的视频和照片**，正在录制的片段不会同步备份
- 备份独立循环策略，可以单独设置备份分区存储上限
- 备份开关独立，默认关闭；外部存储掉线、损坏、无权限时，**完全不影响本机录像功能**
- 空间校验：超出存储可用空间的容量选项自动置灰，不可选择

### 5. 自动化功能
- 开机自启动
- 开机自动开始录像（可开关）
- 循环存储：内置存储独立循环，备份存储独立循环，两套逻辑互不干扰

### 6. 其他配套
- 内置赞赏码、意见反馈、更新下载入口
- 完整免责声明、学习用途说明
- 设置页面：水印开关、GPS开关、存储上限选择、备份管理、设备探测、版本信息
- 空间显示：页面实时展示车机内置存储、外接存储可用空间

## 📖 安装&使用教程
1. 安装：卸载旧版同名包，直接安装APK
2. 权限授予：安装后依次授予【相机权限、存储权限、GPS定位权限】
3. 基础录像：打开APP，预览画面正常后，点击开始录像；支持暂停、停止录像、拍照
4. 局域网访问：在设置页面打开局域网服务，扫描二维码访问网页
5. U盘备份：插入U盘 → 设置 → 外部存储备份 → 开启备份 → 选择授权目录，设置备份上限
6. 开机自启：设置内开启开机自启+自动录像

## ⚠️ 重要注意事项
1. **GPS依赖**：通用版车速来源仅GPS，隧道、地下车库等无GPS信号区域，车速无法获取
2. **VIN读取**：通用版仅尝试系统属性读取VIN，没有厂商私有通道，大部分第三方车机无法读到VIN，属于正常现象
3. **存储说明**
   - 内置存储循环：录像保存在车机本地，循环覆盖
   - U盘备份只是副本，**不能替代本地录像**，U盘拔走不影响主录像
4. 兼容性：仅针对Android 9车机开发，高版本安卓、手机端未做适配，可能出现异常
5. 免责声明：本项目仅用于个人学习研究，录制文件仅作为个人记录使用，**不可替代原厂行车记录仪，不承担事故取证相关责任**
